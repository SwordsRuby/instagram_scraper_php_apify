
# PifPaf AI — Дашборд для блогеров

Управляйте своими Instagram Reels, отслеживайте статистику и анализируйте рост в одном месте.

---

## 📋 О проекте

**PifPaf AI Dashboard** — это веб-приложение для внутренних блоггеров, которое позволяет:

- 📥 Добавлять Instagram Reels по ссылке
- 📊 Автоматически получать статистику (просмотры, лайки, комментарии)
- 📈 Отслеживать общую и среднюю статистику

Данные подтягиваются через **Apify Instagram Scraper API**.

## ⚙️ Установка

### 1. Настройка API ключа

Отредактируйте `api/index.php`:

```php
$APIFY_TOKEN = 'ваш_apify_api_ключ';
```

### 2. Загрузка на хостинг

Загрузите все файлы в `public_html`

### 3. Настройка прав

```bash
chmod 755 ~/public_html/api
chmod 644 ~/public_html/api/index.php
```

---

## 🔧 Настройка Apify

1. Зарегистрируйтесь на [apify.com](https://apify.com)
2. Получите API ключ: **Settings → Integrations → API**
3. Вставьте ключ в `api/index.php`

---

## 📊 Как это работает

1. Пользователь вводит ссылку на Reel
2. Фронтенд отправляет запрос к PHP-прокси
3. PHP-прокси запрашивает данные у Apify API
4. Данные возвращаются и сохраняются в LocalStorage
5. Reel отображается в ленте

## 📱 Функциональность

### Добавление Reel
1. Вставьте ссылку на Instagram Reel
2. Нажмите "Получить данные"
3. Данные автоматически подтянутся

### Статистика
- 📹 Всего Reels
- 👁️ Общие просмотры
- ❤️ Общие лайки
- 📊 Средние просмотры
- ❤️ Средние лайки

### Управление
- 🗑️ Удаление отдельных Reels
- 🗑️ Очистка всех данных

---

## 🔐 Безопасность

- API ключ хранится **только на сервере**
- Ключ не передается на фронтенд
- Все запросы к Apify идут через серверный прокси
